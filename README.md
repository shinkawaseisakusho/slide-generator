# スライドジェネレーター

質問に順番に答えるだけでスライドが作れる、**ログイン不要**のWebアプリです。

表紙タイトル → 表紙サブタイトル → 2枚目の見出し → 内容 → 画像 → 3枚目… とチャット形式で聞いていき、
最後に PowerPoint 形式（`.pptx`）をダウンロードします。
PowerPoint や Keynote など、`.pptx` を開けるアプリでそのまま編集できます。

## 特徴

- ログイン不要・アカウント不要・APIキー不要
- サーバー不要（静的ファイルだけ。処理はすべてブラウザ内で完結）
- **オフライン対応**。一度開けば通信なしでスライドを作れます（下記参照）
- 入力内容も画像も外部に送信されません
- スマホ最適化（大きなタップ領域、カメラ／アルバムからの画像選択、ダークモード対応）
- 1枚のスライドに画像を最大4点まで配置できます
- 入力中の内容は自動保存され、閉じても続きから再開できます
- ダウンロード前に、確認画面で全スライドの仕上がりをプレビューできます
- 途中の「戻る」、最後の確認画面で編集・並べ替え・削除が可能

## 使い方（開発・確認）

`index.html` をブラウザで開くだけでも動きますが、ローカルサーバー経由を推奨します。
インストールは不要です（依存パッケージはありません）。

```bash
cd slide-generator
npm run dev
# → http://localhost:8000
```

起動するとスマホ用のURL（`http://<PCのIPアドレス>:8000`）も表示されるので、
同じ Wi-Fi につないだスマホからそのまま確認できます。

ポートを変えたいときは `PORT=8080 npm run dev`（PowerShell では `$env:PORT=8080; npm run dev`）。

> `localhost` で開いたときは Service Worker を登録しません。
> 開発中にキャッシュが返り続けて、直した内容が画面に反映されなくなるためです。
> 以前に登録されたものが残っていた場合は自動で解除し、一度だけ再読み込みします。
> オフライン対応の動作を確かめたいときは、LAN の IP や公開先（HTTPS）で開いてください。

## 公開する

静的ファイルだけなので、どこにでも置けます。

- **GitHub Pages** … リポジトリに push して Pages を有効化
- **Netlify / Vercel / Cloudflare Pages** … このフォルダをドラッグ＆ドロップ
- 社内サーバーの任意のディレクトリに置くだけでも動きます

いずれも無料枠で足り、HTTPS が付くのでオフライン対応もそのまま有効になります。
`vendor/` を含めてフォルダ一式をそのまま置いてください。

## オフラインで使う

このアプリは PWA として作ってあり、**一度開いたあとは通信がなくても動きます**。
外部CDNへの依存はなく、`.pptx` の生成に使う [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) も
`vendor/` に同梱しています。

1. 通信できる場所で一度アプリを開く（このときに一式が端末へ保存されます）
2. ブラウザのメニューから「ホーム画面に追加」／「アプリをインストール」
3. 以降は機内モードでも起動でき、スライドの作成とダウンロードができます

**通信が必要なのは初回の読み込みだけです。**
それ以降は、スライドの作成もダウンロードもすべてオフラインで完結します。

> Service Worker はブラウザの仕様上 **HTTPS または localhost でのみ有効**です。
> 無料の GitHub Pages・Netlify・Cloudflare Pages はいずれも HTTPS なのでそのまま使えます。
> `file://` で直接開いた場合はオフライン保存が効きません（アプリ自体は動きます）。

アプリを更新して公開するときは、先に `npm run bump` を実行してください。
`sw.js` のキャッシュ版数が上がり、利用者の端末に古い版が残らなくなります。

```bash
npm run bump        # v2 → v3
npm run bump -- 7   # v7 に設定
```

## ファイル構成

| ファイル                   | 役割                                                |
| -------------------------- | --------------------------------------------------- |
| `index.html`               | 画面の骨組み                                        |
| `style.css`                | スタイル（モバイルファースト・ライト／ダーク対応）  |
| `js/`                      | アプリ本体（ES モジュール）                         |
| `sw.js`                    | Service Worker（オフライン対応）                    |
| `manifest.webmanifest`     | PWA の定義（ホーム画面へのインストール用）          |
| `vendor/pptxgen.bundle.js` | PptxGenJS 4.0.1（CDNではなく同梱）                  |
| `icon*.png` / `icon.svg`   | アプリアイコン                                      |
| `server.js`                | 開発用の静的サーバー（`npm run dev`。公開時は不要） |
| `scripts/bump-version.js`  | `sw.js` のキャッシュ版数を上げる（`npm run bump`）  |

`js/` の中身は責務ごとに分かれています。ビルド工程はなく、
ブラウザがそのまま ES モジュールとして読み込みます。

| モジュール         | 役割                                                             |
| ------------------ | ---------------------------------------------------------------- |
| `js/app.js`        | 状態と DOM。質問フロー、確認画面、イベント                       |
| `js/config.js`     | 将来機能の有効・無効を切り替える設定                             |
| `js/layout.js`     | スライドの寸法とレイアウト計算                                   |
| `js/theme.js`      | 配色（テーマ）                                                   |
| `js/pptx.js`       | `.pptx` の組み立て                                               |
| `js/preview.js`    | 確認画面のプレビュー描画（canvas）                               |
| `js/media.js`      | 画像の取り込み、縮小、形式変換                                   |
| `js/storage.js`    | 下書きの保存（IndexedDB／localStorage）                          |

`layout.js` は `pptx.js` と `preview.js` の両方から使います。
寸法とレイアウト判定を1か所に集めることで、**プレビューと実際の仕上がりがずれない**
ようにしています。

## 仕様メモ

- スライドサイズは 16:9
- 画像は長辺 1400px に縮小し、JPEG（品質 0.82）に変換して埋め込みます。
  1.5MB 未満の PNG は透過を保つため PNG のまま扱います
- 内容の改行は段落として反映されます。行頭に `・` `-` `*` を付けると箇条書きになります
- 見出し・本文の文字数に応じてフォントサイズを自動調整します
- デザインは余白と細い罫線だけで構成しています（アプリのUIと同じ考え方）。
  ダウンロード前にテーマカラーを選べます

### テーマカラー

配色だけを差し替える仕組みで、余白や罫線の骨格は全テーマ共通です。
テーマは `app.js` の `THEMES` に定義しており、1行足すだけで増やせます。

選択肢は横4×縦2で並びます。

| キー | 名前 | 背景 | テーマ色 |
| --- | --- | --- | --- |
| `mono` | 白黒（既定） | 白 | ほぼ黒 |
| `blue` | 青 | 白 | 青 |
| `green` | 緑 | 白 | 深緑 |
| `orange` | オレンジ | 白 | 赤茶 |
| `red` | 赤 | 白 | 赤 |
| `purple` | 紫 | 白 | 紫 |
| `beige` | ベージュ | 生成り | 焦茶 |
| `dark` | 黒 | ほぼ黒 | 白 |

テーマ色の上には背景色の抜き文字を置くため、全テーマでコントラスト比を確認しています
（抜き文字と見出しは 4.5 以上、本文は 7 以上）。

テーマ色は次の3か所に大きく出ます。罫線だけの控えめな使い方だと、
どのテーマもほぼ同じに見えてしまうためです。

- **表紙の下端の色帯**（全幅・高さ1.3インチ）。サブタイトルは帯の中に白抜きで置きます
- **中扉の背景全面**。見出しを抜き文字にします
- **本文の見出しの文字色** と、見出し下の罫線の左端に重ねる太い線

表紙はタイトルを上下の細い罫線ではさみ、下の罫線の左端だけ太いアクセントにしています。
本文スライドの見出しとまったく同じ組み方なので、表紙だけ様式が浮きません。
罫線の位置はタイトル枠から自動で決まるため、色帯の高さを変えても崩れません。

本文スライドの下端には細い罫線とページ番号を置いています。本文の領域を削らないよう、
罫線はスライドの下端ぎりぎり（上から 5.16 インチ）に配置しています。

各テーマは `bg`（背景）・`ink`（本文）・`muted`（補助テキスト）・
`line`（細い罫線）・`accent`（テーマ色）の5色で構成されます。

旧バージョンで保存された `navy` / `forest` / `terra` / `sand` / `night` は
読み込み時に新しいキーへ読み替えます。
- 下書きは IndexedDB に自動保存します。IndexedDB が使えない環境では
  localStorage に保存します

### 他のアプリで開いたときの再現性

`.pptx` を読み込むアプリは、PowerPoint 以外にもいくつかあります。
どれで開いてもレイアウトが崩れないよう、次の4点を守っています。

1. **文字の大きさを自前で決める**（自動縮小に頼らない）
   PowerPoint の自動縮小（`normAutofit`）を解釈しないアプリでは、指定どおりの
   大きさで描かれて枠からあふれます。そこで見出しは文字幅から、本文は
   「何行になるか」の見積もりから、最初から確実に収まる大きさを計算します。
   計算はフォントの実測値を使わず「全角1文字＝1em」で行うため、
   どのアプリでも同じ答えになります。

2. **テキストボックスの内側余白を 0 に固定する**
   既定値がアプリによって違い、そのぶん折り返し位置がずれるためです。

3. **行送りを倍率ではなくポイントで指定する**
   倍率の解釈に差が出るのを避けます。

4. **段落の間隔を文字の大きさに比例させる**
   固定値にすると、箇条書きが増えたときにこの間隔だけで枠を食いつぶします。

フォントは Noto Sans JP を指定しています。web で広く配布されているため、
読み込み側での置き換えが起きにくい選択です。

### レイアウト

**内容もメディアもどちらも任意**です。必要なのは見出しだけで、有無の組み合わせに応じて
レイアウトを自動で切り替えます。

| 内容 | メディア | レイアウト |
| --- | --- | --- |
| あり | あり | 左に文章、右にメディアの2分割 |
| なし | あり | メディアを全幅で配置 |
| あり | なし | 文章を全幅で配置 |
| なし | なし | 見出しを中央に大きく置く中扉スタイル |

1枚のスライドに **最大4点** のメディアを並べられます。配置は領域の縦横比から自動で決まります。

| 点数 | 横長の領域（メディアのみ） | 縦長の領域（文章と併用） |
| --- | --- | --- |
| 1 | 全体に1点 | 全体に1点 |
| 2 | 横に2分割 | 縦に2段 |
| 3 | 横に3分割 | 縦に3段 |
| 4 | 2×2 のグリッド | 2×2 のグリッド |

1点のときは画像の全体が見えるように収め（contain）、複数点のときは端を切ってセルを埋めます（cover）。
縦横比の違う写真が混ざってもグリッドの辺が揃うようにするためです。
